# Appendix C: Built This Way {#network}

Every product below was built by a small number of humans directing a fleet of agents, using the workflow in this book. Some are developer tools you can use today. Some are consumer products that exist mostly to prove the method works on real, messy, shipping software. Status changes fast, so check the site before you depend on anything.
