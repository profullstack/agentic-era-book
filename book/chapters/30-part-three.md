# Part III: The Loop {.part}

> Nobody gets paid for a branch. You get paid for software somebody is using.

The workbench is set up. Now you have to turn it into a habit that runs every day, on every repo, whether the change is a typo or a payment rail. This part is about the loop we run on about 170 repositories: frame the work, fan it out, gate it, merge it, ship it, check that it is actually live, and then tell somebody it exists.
