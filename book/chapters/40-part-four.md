# Part IV: Running the Fleet {.part}

> One agent is a tool. Twenty agents are an organization, and organizations need keys, money, names and power.

Once agents ship code every day, the boring questions arrive fast. Who holds the keys? How does an agent pay for an API call, or get paid for a bounty? What is its name, who owns it, and which GPU answers when it thinks? This part covers the plumbing that turns a pile of agents into a fleet you can trust.
