A field guide · 2026

Code got cheap.
Everything around it did not.

This book was written the way it describes: an engineer framed it, AI agents drafted it in parallel, and a human decided what made the cut. It is a field guide for engineers who already know how to program and want a system around their coding agents instead of a pile of habits.

  • The Shift. Why typing stopped being the bottleneck, and how agents fail.
  • The Workbench. The terminal, a browser agents can drive, pairing, a stack agents can read.
  • The Loop. Frame, fan out, gate, review, ship everywhere, tell somebody.
  • Running the Fleet. Keys, money for machines, identity for agents, compute on tap.
  • The People. Careers, and a playbook you can start on Monday.
